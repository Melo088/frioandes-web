    Every environment comes from the same code.

    Terraform modules for the network, security and ingestion, deployed by GitHub Actions with OIDC. No address range or firewall rule is typed by hand: modules read the verified data files and check their hashes first.

      Network module

      Virtual network and 11 subnets per environment, read from the verified address plan.

      Security module

      Shared firewall policy and per-subnet controls, generated from the policy table.

      Ingest module

      Private event buffer for temperature alerts, tested with a mocked provider.

      Change window

      Deployments are blocked from 04:00 to 22:00 and during peak seasons. Cloud promotion ships disabled until the real subscription exists.
